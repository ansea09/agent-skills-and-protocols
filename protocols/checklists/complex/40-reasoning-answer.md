# Reasoning And Answer Support

Supports C3-C6 of [the complex checklist](00-master.md).

Use the domain language. Select viewpoints by different questions and criteria,
not by role labels alone. Compare alternatives only where a choice remains
open; do not manufacture a rival just to fill a form.

Separate observations, source statements, assumptions, hypotheses,
recommendations, decisions and performed work. Use the shared routes for
relations, measurement, temporal and causal questions as applicable.

An editor's shorter explanation must preserve substantive conditions. Put a
limit that changes use beside the affected claim, not only in audit metadata.
For example, new diagnostics may not reproduce or explain an earlier failure.

Perform only authorized changes and verify the resulting artifacts.
